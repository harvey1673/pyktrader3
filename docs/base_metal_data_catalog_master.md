# 基本金属数据总汇总与标记规则

本文件对应汇总表: docs/base_metal_data_catalog_master.csv。

## 覆盖范围

- 再生铅
- 原生铅
- 铜
- 锌
- 镍链（Ni/NPI/MHP/不锈钢）
- 铝（Al）
- 氧化铝（AO）
- 锡（Sn）

## 字段说明

- 品种: 数据所属金属或链条
- 数据源: SMM/Wind/Reuters/Mysteel/iFind
- 用途大类: 销售收入、原料成本、能耗成本、副产品收益、汇率、物流、融资等
- 指标名称: 数据原始或标准化名称
- 数据ID: 平台ID或内部TODO占位ID
- 是否直接进入利润: 对利润计算的直接程度（★★★★★到★，或文字说明）
- 建议模型层级: Model1(交易)/Model2(研究)/Model3(Sell-side)
- 优先级: 高/中/低
- 状态标签: 已映射/待映射
- 备注: 来源或分组标签

## 标记规则（建议统一）

### 1. 模型层级标记

- Model1(交易): 日更且直接驱动利润方向的核心变量
- Model2(研究): 用于解释分解和归因的扩展变量
- Model3(Sell-side): Excel全量对齐变量，仅用于深度校验

### 2. 优先级标记

- 高: 缺失会明显影响利润方向判断
- 中: 影响解释能力但不改变主方向
- 低: 主要用于补充说明或季度复盘

### 3. 状态标签

- 已映射: 可直接对接到现有ID映射或现有序列
- 待映射: 需要补全ID映射或数据接入

## 使用建议

1. 先筛选 Model1(交易)+高+待映射，作为首批补数清单。
2. 再推进 Model2(研究)+高/中，构建解释框架。
3. 最后按 Model3(Sell-side) 做月度校验，不强制日更。
