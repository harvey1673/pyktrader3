1. 研究出发点
量价类因子与基本面因子构建逻辑和收益表现具有低相关性， 可以作为基本面因
子补充。我们尝试用一种非逻辑性因子生成方式，对交易型量价因子进行 系统挖掘。
本文第一部分对alpha101 因子在A 股市场有效性和相关性进行探讨， 筛选出有效性、
独立性较强的量价因子构建基础量价因子库； 第二部分，基于遗传规划算法进行量价
因子再挖掘，保证因子风格中性化后仍具有较强有效性。
2. 量价因子有效性
2.1. alpha 因子拆解：基本函数与算子组合
我们解析的 alpha 因子基础数据包括开盘价（open）、收盘价（close）、最高
价（high）、最低价（low）、成交量（volume），以及衍生指标包括日度收益率
（return）、成交加权价（vwap），并以算子形式进行公式分解； 通过组合时序、
截面上的量价特征， 以明确公式呈现因子构建过程， 相比传统技术指标等， 精细度和
准确性更高，信息维度也更为丰富；传统技术指标更多关注个股时序特征，alpha 因
子增加截面维度以及变量相关关系信息 （如rank、correlation） 特征。WorldQuant
Alpha101 相关文献中提及的基本函数如下所示：
 sign(x) :符号函数，x>0，返回 1；x<0，返回-1；x=0 时，返回 0;
 rank(x)：按照变量 x 进行截面排序
 delay(x,d)：d 日前 x 变量值
 correlation(x,y,d) ：过去 d 日变量 x, y 时序相关系数
 covariance(x,y,d) ： 过去 d 日变量 x,y 时序协方差
 scale(x,a)：标准化变量 x，使得 sum(abs(x`))=a，则 x` = x*a/sum(abs(x))
 delta(x,d):  选取变量 x 当前值与 d 日前的差值
 signedpower(x,a)：变量 x 的幂运算，x^a
 decay_linear(x,d):  d 日衰减加权平均，加权系数为 scale（D，1），D=d,d–
1,…,1
 ts_{O}(x,d)：ts 开头均为时序操作，在过去 d 日变量 x 上进行操作
 ts_min(x,d)：过去 d 日变量 x 的最小值，min(x,d)=ts_min(x,d)
 ts_max(x,d)：过去 d 日变量 x 的最大值, max(x,d)=ts_max(x,d)
 ts_argmax(x,d)：过去 d 日 x 最大值发生的日期
